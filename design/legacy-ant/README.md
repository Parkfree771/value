# 옛 개미 캐릭터 원본 (보관용)

2026-10-30 에디토리얼 디자인 개편 때 사이트에서 뺀 개미·로고 원본. 사이트에서 서빙하지 않는다(`public/` 밖).
개미를 신문 톤으로 리디자인할 때 참고용.

- `sprite_*.webp` — 로그인 화면에서 걷던 픽셀 개미 (logo + 4프레임)
- `favicon.png` — 옛 개미 파비콘
- `logo.webp`, `logo-background.webp`, `og-antstreet-logo.png`, `3_A.png` — 옛 입체 로고들

`public/logo.png` 는 영상 생성기(`scripts/video-maker`)가 아직 써서 그대로 둠.
